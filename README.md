# 🎛️ SwitchMatrix & Visual Switch Manager for Home Assistant

**SwitchMatrix** is a production-ready, protocol-agnostic visual automation studio and Home Assistant integration. It automatically detects, abstracts, and automates any switch, relay, button, remote, or wall switch connected to Home Assistant.

---

## ⚡ Highlights

* **Universal Hardware Support**: Seamlessly normalizes Matter/Thread, Zigbee (ZHA & Zigbee2MQTT), Z-Wave JS, Shelly/WiFi, ESPHome, and Bluetooth.
* **Interactive Digital Twin Canvas**: Realistic SVG vector twins with real-time hover feedback, click-to-configure zones, and ripple effects.
* **Visual Flow Builder**: Easily construct automations: `[Switch Trigger] -> [Condition (Sun/Time/State)] -> [Action / Presets]`.
* **Real-Time YAML Synthesis & 1-Click Save**: Instant preview of synthesized Home Assistant automations with syntax validation and automatic reloading.

---

## 🚀 Installation

1. Copy `custom_components/switchmatrix` into your Home Assistant `config/custom_components/` directory.
2. Restart Home Assistant (*Settings -> System -> Restart*).
3. Go to **Settings -> Devices & Services -> Add Integration -> SwitchMatrix**.
4. Access **SwitchMatrix** from the sidebar!
